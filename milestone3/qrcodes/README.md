QR Codes
========

My initial idea for how to implement the Benaloh challenge relies on being able
to give the voter a copy of their encrypted vote (at least the hash) via QR
code, so I want to be sure they can handle that much info before getting too
far down that track.

Looks like it shouldn't be a problem! Here's a quick mockup with scripts:

* [create-test-gpgkey.sh](create-test-gpgkey.sh)
* [sign-and-print-json-qrcode.sh](sign-and-print-json-qrcode.sh)
* [scan-qrcode.py](scan-qrcode.py)
* [scan-and-verify-qrcode.sh](scan-and-verify-qrcode.sh)
